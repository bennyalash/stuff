The Owner's Closet

Purpose

I created The Owner's Closet for GT Vacation Rentals to simplify and modernize the management of multiple rental properties. The primary goal was to provide a single, intuitive interface for tracking availability, managing bookings, and coordinating with guests and property staff, reducing errors and saving valuable time.

Before this tool, managing multiple calendars across platforms was time-consuming and error-prone. The Owner's Closet consolidates bookings into a centralized system that is easy to read, update, and maintain.

How It Works

The app is built with React for a responsive, dynamic frontend experience, and Firebase for secure authentication and real-time database management. Users can sign in, view property availability on an interactive calendar, and see all upcoming reservations at a glance.

The Owner's Closet supports adding new bookings, editing details, and marking dates as unavailable. All changes are automatically synced in real time across devices, ensuring everyone has the latest information without manual updates.

Key Features

  • Centralized calendar view for multiple properties
  • Real-time updates and synchronization via Firebase
  • User authentication and secure data access
  • Add, edit, and manage bookings seamlessly
  • Responsive design for desktop and mobile

Technology Stack

  • React
  • Firebase (Auth + Firestore)
  • HTML5 & CSS3
  • Vite (React tooling)

Impact

The Owner's Closet has become an essential tool for GT Vacation Rentals, helping manage multiple properties efficiently and reducing double-bookings. The real-time sync and user-friendly interface have improved communication with guests and staff, ultimately saving hours of administrative work each week.

This project demonstrates my ability to take a real-world problem, design a practical solution, and implement it using modern web technologies, while keeping the user experience simple and effective.
